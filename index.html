Definiciones de HTML, CSS y JavaScript

HTML:
Es el lenguaje que se utiliza para crear la estructura y el contenido de una página web, como títulos, textos, imágenes y botones.

CSS:
Es el lenguaje que permite cambiar la apariencia de una página web, por ejemplo, los colores, tamaños, tipos de letra y distribución de los elementos.

JavaScript:
Es un lenguaje que permite agregar acciones y funciones a una página web, haciendo que pueda responder a lo que hace el usuario.
